# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML5, CSS3 and vanilla JavaScript (ES modules), no build step. Hosted on GitHub Pages as a project site (`dandavd.github.io/GameDevWebPortfolio/`), so every path is relative.

## Users

Game-development recruiters, indie studio leads and technical hiring managers deciding whether to interview Daniel David. They skim on a desktop at work or on a phone, often with sound on for something else.

## Product Purpose

A portfolio that gets Daniel an interview as a generalist game developer and C++/C# systems programmer. Success: within seconds a visitor knows who he is and what he does, and within a minute they can open each game and see the engineering behind it.

## Positioning

Three original, solo-built games whose engineering is shown in the open: a Unity 6 digital board game of conquest with an engine-free C# core balanced via headless simulations, a C++20 boss fight on raylib with its own loop, AI and synthesized sound, and a Unity 6 co-op horror game driven by the player's voice. All three ship with automated tests and clean architecture.

## Operating Context

Visitors arrive from a CV, LinkedIn or GitHub. They compare candidates quickly, then go to the repositories and releases to verify claims.

## Capabilities and Constraints

- Projects load from a JavaScript data file and open in a detailed modal.
- Sections: hero with links, projects, career and education, self-rated skill meters, research placeholder.
- The site is silent: no audio.
- Each project modal shows one YouTube gameplay showcase (no GIF slot). The Itch.io button appears only when a game page exists.
- Echo Protocol proximity voice chat is done (confirmed by Daniel on 2026-11-01).

## Brand Commitments

- Dark, Souls-like atmosphere, strictly professional and readable. An homage to the genre: no assets, fonts or sounds taken from any real game.
- Easter eggs: a "YOU DIED" screen for the 404 page and for errors, and a concealed bonfire secret.
- Project quotes are deadpan motivational lines approved by the owner.

## Evidence on Hand

- CV (Oct 2026), GitHub READMEs, GodBoard (Official 2026 Unity Game Jam), Horde Carnage v1.0.0 and Echo Protocol v0.2.0 releases.
- GodBoard screenshots from its repository (`assets/projects/godboard/`).
- Echo Protocol screenshots from its repository (`assets/projects/echo-protocol/`).
- Horde Carnage gameplay screenshots (`assets/projects/horde-carnage/`).
- Never invent testimonials, employers, players, press or numbers.

## Product Principles

- Facts a recruiter can verify beat adjectives.
- Personality lives in details; it never slows down reading.
- Every claim on the page matches the repository it links to.
